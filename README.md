# lab_1_getting_started_with_quantum
Lab 1 for Qiskit Fall Fest at the University of Bristol. Modified from lab notebooks provided by IBM Quantum for Qiskit Fall Fest.

background_notes explains some maths (linear algebra/vectors/matrices and complex numbers) and some classical computing concepts. This is expected to be familiar for most students.
Lab_1_notes explain some of the quantum information theory that is useful to know. This is expected to be new for most students.
get-started-with-qiskit_fallfest.ipynb is the coding notebook.
